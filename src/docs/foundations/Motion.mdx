# 모션

모션은 `<html>`(또는 하위 트리)의 `data-motion`(`full`, `reduced`, `off`)을 따릅니다. 프로바이더가 없어도 OS의 "동작 줄이기" 설정이 켜져 있으면 `reduced`와 같은 값이 적용됩니다(`data-motion="full"`로 명시한 경우 제외).

이 문서가 모션 사양의 정본입니다. 아래 표의 토큰과 유틸리티만 사용합니다.

## 규칙

- 열림/닫힘은 Base UI의 `data-starting-style` / `data-ending-style` 사이의 CSS 트랜지션으로 만듭니다. 트랜지션은 도중에 취소되어도 끊기지 않습니다.
- 지속 시간은 `var(--motion-*)` 토큰, 이징은 `ease-yorha-*`로만 씁니다. 레지스트리 `.tsx`에 `180ms` 같은 숫자, `cubic-bezier(...)`, `transition-all`을 직접 쓰지 않습니다(`pnpm registry:lint`의 `motion` 규칙).
- 나가는 동작은 들어오는 동작보다 빠르고, 이징은 `ease-yorha`입니다(`ease-yorha-in`은 처음이 느려 지연처럼 보이므로 UI 이탈에 쓰지 않습니다). 예외는 드로어: 이탈도 `--motion-drawer`이며 스와이프로 놓으면 `--drawer-swipe-strength`만큼 줄어듭니다. 아코디언·콜랩서블은 이탈 `--motion-select`, 탭 패널은 열 때만 `--motion-select` 페이드입니다.
- Base UI가 `data-instant`를 붙인 열림/닫힘(키보드로 연 팝업, Esc, 포커스 툴팁)은 `yorha-pop`, `yorha-panel`, `yorha-fade`가 애니메이션 없이 바로 표시합니다.
- 팝업은 `--transform-origin`(Base UI Positioner가 설정)에서 커집니다.
- 깜빡임은 초당 3회 이하, 5초를 넘는 자동 동작에는 일시정지 수단을 둡니다.
- 로딩 표시(Spinner, 불확정 Progress, Skeleton, Button `loading`)는 마운트되어 있는 동안 `--motion-loop` 주기로 반복합니다. 멈춘 로더는 "끝났다/멈췄다"로 읽히기 때문입니다. `reduced`는 느린 주기(2400ms)의 불투명도 펄스만, `off`는 정지하되 줄무늬·단계 불투명도로 "진행 중"임을 보입니다.

구현 방식: 모든 지속 시간 토큰은 `reduced`와 `off`에서 0입니다. 유틸리티는 불투명도에 `max(토큰, var(--motion-reduced-fade))`를 써서 `reduced`에서만 짧은 페이드를 남기고, 이동 거리와 배율에 `var(--motion-spatial)`(1 또는 0)을 곱해 공간 이동을 없앱니다. 토큰을 직접 쓰는 코드(`duration-(--motion-select)`)는 `reduced`에서 자동으로 즉시 전환됩니다.

### 조합할 때

- 열림/닫힘 유틸리티(`yorha-pop`, `yorha-panel`, `yorha-fade`, `yorha-slide-*`, `yorha-collapse`, `yorha-wipe`)와 `yorha-press`는 요소의 `transition`을 통째로 정합니다. 같은 요소에 `transition-*`, `duration-*` 클래스를 함께 쓰지 않습니다. 한 요소에는 이 유틸리티 중 하나만 씁니다.
- `yorha-slide-*`의 이동 거리는 `--yorha-slide-distance`(기본 `100%`, 자기 크기)로 바꿉니다. 토스트는 전용 유틸리티 없이 같은 토큰으로 조립합니다(`registry/yorha/ui/toast/toast.tsx`).
  - 쌓임: 모든 토스트는 `bottom-0`에 놓고 `transform: translate(var(--toast-swipe-movement-x), calc(var(--toast-swipe-movement-y) - (var(--toast-offset-y) + var(--toast-index) * 0.5rem)))`로 올립니다. 하나가 사라지면 남은 토스트가 `transform` transition으로 내려앉습니다(레이아웃 점프 없음).
  - 진입/이탈: `data-[starting-style]`·`data-[ending-style]`에서 `opacity: 0`과 `translate`(오른쪽 1rem × `--motion-spatial`). 진입 `--motion-panel`, 이탈 `--motion-panel-exit` + `ease-yorha-in`. 이동량에 `--motion-spatial`을 곱하므로 reduced는 불투명도만, off는 즉시.
  - 스와이프: 드래그 중에는 Base UI가 inline `transform`으로 손을 따라가고(`data-swiping`에서 transition 0), 놓으면 `data-swipe-direction`에 맞춰 `--toast-exit-x/y`(`calc(100% + 1rem)`)만큼 `translate`가 같은 방향으로 이어 나가며 사라집니다. 제자리로 되돌아가지 않습니다.
- `yorha-slide-*`는 Base UI Drawer의 `--drawer-swipe-movement-x/y`, `--drawer-snap-point-offset`, `--drawer-swipe-strength`, `data-swiping`을 읽습니다. Drawer가 아닌 요소에서는 이 값들이 없으므로 영향이 없습니다.
- `yorha-stagger`는 CSS 애니메이션이라 Base UI 속성 없이 마운트 시 한 번 재생됩니다. 인덱스를 주지 않으면 지연 없이 나타납니다.
- 유틸리티가 없는 전환(탭 표시선, 라우트 전환, 공유 요소)은 토큰을 직접 씁니다: `transition-[left,width] duration-(--motion-tab-indicator) ease-yorha-emphasized`. `reduced`에서 페이드를 남기려면 불투명도에만 `max(var(--motion-route), var(--motion-reduced-fade))`를 쓰고 이동 거리에 `var(--motion-spatial)`을 곱합니다.

### 금지 목록

글리치·플리커를 컨트롤, 호버·프레스·입력, 본문, 값, 다이얼로그 제목, 드래그 오버레이에 쓰는 것. 한 요소에서 1초에 한 번을 넘는 효과. 스피너·스켈레톤·불확정 진행률·버튼 busy·스위치 pending 밖의 무한 반복. 클립이나 마스크를 불투명도와 한 `@keyframes`에 넣는 것(컴포지터에서 떨어짐). `@keyframes`에서 `text-shadow`, `filter`, `box-shadow`, 레이아웃 속성을 움직이는 것. `.tsx`에 직접 쓴 `steps(...)`, `ms`, `cubic-bezier`(대신 `--yorha-step-*`, `ease-yorha-step-*`, `--motion-*`). `will-change`. `yorha-wipe` / `yorha-press`가 있는 요소에 다른 효과. 스크림의 디졸브, 툴팁의 스캔. 글리프의 `scale`, `rotate`. `pnpm registry:lint`가 앞의 여러 항목을 잡습니다(`fx-keyframes-mix`, `fx-keyframes-props`, `motion`의 `steps(`, `fx-on-control`, `pixel`).

### 모드별 동작

- `reduced`: 불투명도만. 클립·마스크·이동·단계 이징 없음(스텝 이징 토큰은 `linear`, 마스크 토큰은 `none`). 120ms 이하의 단조 페이드만 남고, 캐럿은 켜진 채, 글리치 레이어는 보이지 않습니다.
- `off`: 아무것도 움직이지 않습니다. 모든 지속 시간 토큰이 0이고 `data-run`은 `runFx`가 바로 지웁니다.
- 강제 색상: 글리치 채널 레이어는 `display: none`, 캐럿·디더·점은 `CanvasText`, 디졸브는 알파 마스크라 그대로 동작합니다.
- 휴지 상태는 v3와 같습니다. 어떤 효과도 클립·마스크·변형·불투명도를 남기지 않고, 어떤 박스도 바꾸지 않습니다.

### 일회성 효과 재생(`data-run`)

`yorha-glitch`, `yorha-flicker`는 호스트에 `data-run`이 있는 동안에만 재생됩니다. 마운트될 때 한 번이면 `data-run=""`을 JSX에 고정하고, 마운트된 요소를 다시 재생할 때는 `runFx(el)`(`lib/utils/fx.ts`)를 부릅니다. `runFx`는 같은 요소에서 마지막 실행 후 1000ms가 지나지 않았으면 아무것도 하지 않고 `false`를 돌려줍니다(이 하한은 낮출 수 없음).
