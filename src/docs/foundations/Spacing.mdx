# 간격과 밀도

**픽셀 그리드는 4px로 고정**입니다(`--spacing` = 0.25rem, 밀도가 바꾸지 않음). 높이와 세로 간격은 4px의 배수(헤어라인 오프셋만 2px), 고정 px 자식을 가운데 놓는 상자는 짝수 크기, 텍스트나 테두리 상자에 퍼센트 translate 금지, 소수 px/rem 임의값 금지입니다.

밀도(`data-density`)는 간격이 아니라 **크기 토큰**을 하위 트리 단위로 바꿉니다. 컨트롤 높이는 패딩+줄 높이로 만들지 않고 `h-control-*`(줄바꿈 가능하면 `min-h-*`)로 정하고 내용을 가운데 놓습니다.

  </thead>
  <tbody>

`h-control-md`, `size-control-sm`, `min-h-row`, `px-pad-md`, `size-icon-md`처럼 씁니다. 아이콘·인디케이터·불릿은 밀도와 무관하게 고정입니다.

## 간격 · 모서리 · 테두리

모서리 반경은 항상 0입니다. 포커스 표시는 `focus-visible:yorha-focus`(2px 잉크 외곽선 + 2px 오프셋)를 씁니다. `--menu-rule`은 선택된 메뉴 행 위아래의 얇은 선이며 0으로 두면 꺼집니다.
