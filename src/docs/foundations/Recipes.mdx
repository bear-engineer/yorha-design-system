# 상태·행·표면 레시피

컴포넌트는 hover·pressed·disabled·read-only·invalid를 **직접 쓰지 않고 아래 유틸리티**로 만듭니다. 상태는 컨트롤의 크기를 바꾸지 않습니다(배경색, 테두리색, 안쪽 그림자만).

## 상태

색은 테마마다 다시 계산되는 `color-mix`입니다. 세기는 토큰(`state.*`, 퍼센트)이고 high-contrast 테마는 더 진하게 덮어씁니다.

색 유틸리티: `bg-yorha-hover`, `bg-yorha-pressed`, `bg-yorha-range`, `text-yorha-disabled`, `border-yorha-disabled`, `bg-yorha-disabled`.

| 상태 | 레시피 | 클래스 |
|---|---|---|
| hover, 동작 버튼 | 잉크 와이프 | `buttonVariants` |
| hover, 상태가 있는 컨트롤(체크 상자, 토글, 탭, 달력 날짜, 표 행, 카드 링크) | 배경 `--yorha-hover`만, 크기·scale 없음, 마우스 같은 정밀 포인터에서만 | `yorha-tint` |
| pressed, 단독 버튼 | scale 0.97 | `yorha-press` |
| pressed, 묶음 항목·행·셀 | 배경 `--yorha-pressed`, 전환 0s, scale 없음 | `yorha-tint` |
| 선택됨 / 체크됨 / 현재 | 잉크 채움, 잉크 위 글자, 색만으로 표시하지 않음 | 컴포넌트 |
| disabled | 불투명도 없음. 글자·테두리 `--yorha-disabled`, 채움·그림자·scale 제거, `cursor: not-allowed`. 체크된 disabled는 표시(채움 `--yorha-disabled`, 내용 `--yorha-bg`)를 유지. forced-colors는 `GrayText` | `yorha-disabled` |
| read-only | 글자 그대로, 채움 없음, 아래 테두리만(인쇄된 양식 선), `cursor: default`, 포커스는 가능 | `yorha-readonly` |
| invalid | 테두리 `--yorha-alert-ui` + `inset 0 0 0 1px`(2px 가장자리, 크기 불변). 아이콘과 문구를 함께 | `yorha-invalid` |

`yorha-tint`는 `:disabled`, `[data-disabled]`, `[aria-disabled]`, 선택됨(`[data-checked]`, `[data-pressed]`, `[aria-pressed=true]`, `[data-selected]`, `[aria-selected=true]`), `[aria-current]`, `[data-highlighted]`, `[data-popup-open]`, `[data-panel-open]`에서는 적용되지 않습니다.

텍스트 필드 프레임의 hover는 `hover:border-yorha-fg`(포커스·invalid·disabled·read-only 제외)입니다.

### 마이그레이션 (B5)

`disabled:opacity-*`는 사라집니다. 칠해지는 상자에 `yorha-disabled`를 쓰고, 라벨·설명은 `data-[disabled]:text-yorha-disabled`를 씁니다.

## 형태와 리듬 (G5)

- 모서리는 `rounded-yorha`(0)만 씁니다. 테두리는 컨트롤 프레임·표면에 1px `border-yorha-border`, 구분선에 1px `border-yorha-separator`입니다. 2px는 포커스 링, invalid 가장자리(안쪽 그림자), 가장자리에 붙은 시트의 안쪽 선, 달력 오늘 막대에만 씁니다. 상태가 `border-width`를 바꾸지 않습니다. 잉크로 채운 컨트롤은 `border-yorha-ink`를 유지합니다.
- 그림자: 팝업은 `shadow-yorha-md`, 가운데 모달과 끌고 있는 오버레이는 `shadow-yorha-lg`, 패널 안 카드와 가장자리 시트에는 없습니다.
- 4px 그리드 리듬: 아이콘↔라벨 8, 라벨↔컨트롤 8, 컨트롤↔설명·오류 4, 필드↔필드 24, 한 줄 컨트롤 8, 팝업 안쪽 16(메뉴는 위아래 4·좌우 0), 카드·패널 24(640px 미만 16), 대화상자 헤더·본문·푸터는 같은 좌우 여백(24, 640px 미만 16), 툴바·그룹 구분선은 1px×24px.

## 포커스 (G6)

`yorha-focus`(2px `--yorha-ring`, 오프셋 2px)가 기본이고 **칠해진 컨트롤 상자**에 그립니다. 잘리는 컨테이너나 테두리를 나눠 쓰는 곳의 맞닿은 항목(아코디언·접기 트리거, 탭, 표 정렬 버튼, 툴바·토글 그룹 항목, InputGroup 버튼, 스크롤 영역 뷰포트)은 `yorha-focus-inset`을 씁니다. `currentColor`라 잉크 위에서도 보입니다.

| 경우 | 규칙 |
|---|---|
| 라벨 + 상자(체크, 라디오, 스위치) | 상자에 링 |
| 복합 필드 | 프레임에 한 번: `has-[[data-slot=input-group-control]:focus-visible]:yorha-focus`, 안쪽 컨트롤은 `outline-none`. 열린 팝업이 두 번째 어두운 테두리를 더하지 않음 |
| 팝업·목록의 강조 행 | 링 없음, 채움이 표시: `focus-visible:outline-none forced-colors:focus-visible:yorha-focus-inset` |
| 맞닿은 셀 격자(달력) 안 | 기본 링 + `relative z-10` |
| 카드 전체 링크 | 카드에 링: `has-[a:focus-visible]:yorha-focus`, 링크는 `outline-none` |

## 행 (G8)

`yorha-row`는 menu, context-menu, menubar, select, combobox, autocomplete, menu-list, navigation-menu의 모든 행에 쓰는 하나의 모델입니다. 팝업은 위아래 4px 패딩만 있고 좌우 패딩이 없어 채움이 테두리에 닿습니다. 강조(`data-highlighted`)는 잉크 한 겹이 90ms(`--motion-press`)에 왼쪽에서 채워지고, 떠나는 행은 0s에 즉시 사라져 와이프가 한 번에 하나만 보입니다. disabled 행은 강조되지 않고 `--yorha-disabled`입니다. forced-colors에서는 `Highlight` 2px 안쪽 윤곽입니다.

행 구조(여덟 곳 공통): `[커서 12px: TriangleIcon, 강조 시 opacity 0→1] [표시 슬롯: span.grid.size-indicator.shrink-0.place-items-center (data-slot=row-indicator)] [라벨: flex-1 min-w-0 truncate] [뒤: 단축키(text-yorha-xs, mono, tabular, soft) | ChevronIcon 12 | 없음]`.

표시 슬롯은 팝업(`[data-slot$=-content]`)에 `menuitemcheckbox`, `menuitemradio`, `option` 행이 있을 때만 보입니다. 단순 동작 행에는 불릿이 없습니다. 목록 행은 `[--yorha-wipe-exit:0s]`를 씁니다.

## 오버레이 표면 (G10)

- `yorha-surface`: 패널 바탕, 1px 테두리, 모서리 0, `4px 4px 0 0 var(--yorha-shadow)`. 떠 있는 모든 팝업이 씁니다(툴팁만 예외: 잉크 칩, 그림자 없음). 모달은 `yorha-surface shadow-yorha-lg`, 스크림은 `bg-yorha-scrim`입니다. 가장자리 시트(드로어)는 오프셋 그림자 없이 안쪽 가장자리 2px 잉크 테두리입니다.
- `yorha-scroll`: `overflow: auto`, `overscroll-behavior: contain`, 얇은 스크롤바. `yorha-scroll-cue-x`: 가로로 스크롤되어 가장자리에서 벗어났을 때만 그 쪽에 1px 선이 나타납니다(표). 호스트 배경이 페이지 배경이 아니면 `--yorha-scroll-ground`를 지정합니다.
- 위치 기본값: popover·preview-card·tooltip은 각자 기본 side/align, 간격 8, 내용 크기(`max-w-[min(20rem,var(--available-width))]`). menu·select·combobox·autocomplete·date는 아래/start, 간격 8, select·combobox는 앵커 너비, menu는 `min-w-56`. 하위 메뉴는 inline-end/start, `sideOffset -1`, `alignOffset -4`. 메뉴바는 막대 아래 8. 모두 `collisionPadding 8`, `max-h-(--available-height)` + `yorha-scroll`, `transform-origin: var(--transform-origin)`.
