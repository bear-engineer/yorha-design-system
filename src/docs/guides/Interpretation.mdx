# 원작 재해석 원칙

이 프로젝트는 비공식 팬 프로젝트이며 Square Enix·PlatinumGames와 관련이 없습니다. 상업적으로 사용하지 않습니다.

## 유지한 시각적 특징

베이지 패널과 희미한 격자, 직각 모서리, 어두운 선택 행과 왼쪽에서 오른쪽으로 채워지는 동작, 사각 불릿과 가는 선, 규칙적인 글자 간격을 새 CSS와 토큰으로 표현합니다.

## 접근성을 위해 바꾼 점

기본·다크·고대비 테마는 텍스트와 조작 요소의 대비를 검사합니다. 키보드 포커스를 보이게 하고, 색상이나 hover만으로 상태를 전달하지 않습니다. 모션 줄이기와 사운드 끄기를 지원합니다. `authentic` 테마는 원작에 가까운 장식 실험으로 대비 기준을 충족하지 못하므로 장식에만 쓰고 필수 정보나 조작에 쓰지 않습니다.

## 지식재산과 자료

원작 폰트, 로고, 효과음, 스크린샷, 트레이스한 SVG를 포함하지 않습니다. 장식은 CSS로 그리고, 폰트는 OFL 라이선스를 사용하며, 사운드는 절차적으로 생성합니다. 비공식 고지는 권리 사용 허가를 뜻하지 않습니다.
