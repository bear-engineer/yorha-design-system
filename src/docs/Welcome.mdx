# YoRHa 디자인 시스템

NieR:Automata의 YoRHa UI를 재해석한 **비공식 팬 프로젝트**입니다. Square Enix·PlatinumGames와 관련이 없으며 상업적으로 사용하지 않습니다.

이 Storybook은 토큰, 컴포넌트, 레이아웃과 사용법의 정본입니다. 사이드바에서 각 항목의 예제와 접근성 동작을 확인하세요. 레지스트리 항목은 필요한 소스만 앱으로 복사합니다.
